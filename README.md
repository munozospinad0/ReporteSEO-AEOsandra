## Cómo activar GitHub Pages

1. Ir a **Settings → Pages** del repositorio
2. En **Source**, seleccionar **Deploy from a branch**
3. En **Branch**, seleccionar `main` y carpeta `/ (root)`
4. Guardar

GitHub Pages publica el `index.html` en pocos minutos en:
`https://munozospinad0.github.io/ReporteSEO-AEOsandra/`

## Compartir el reporte

- **Por email/WhatsApp:** mandar el link de GitHub Pages
- **Como PDF:** abrir el reporte en navegador → Ctrl+P → "Guardar como PDF"
- **Offline:** mandar el archivo `index.html` directamente
